# OrcaGif – 免费且注重隐私的 GIF 制作与编辑工具

[English](README.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [العربية](README.ar.md) · [हिन्दी](README.hi.md) · **中文** · [বাংলা](README.bn.md) · [Português](README.pt.md) · [Bahasa Indonesia](README.id.md)

把视频变成 GIF，编辑已有的 GIF，或把结果保存为体积更小的 WebP 或 WebM。OrcaGif 只有一个 HTML 文件，一切都在你的浏览器本地运行：不上传、无需账号、没有 Cookie。

## 快速开始
1. 在浏览器中打开 `OrcaGif.html`。
2. 选择顶部的标签页：**🎬 视频转 GIF**（用视频制作 GIF）或 **🎨 GIF 编辑器**（编辑已有的 GIF、图片、视频、WebP 或 WebM）。
3. 选择文件类型（GIF、WebP 或 WebM），点击蓝色按钮，然后下载结果。

> 页面顶部的“使用方法 – 快速指南与常见问题”用简单的语言介绍了同样的步骤，支持全部 10 种语言。

## 该选哪种文件类型？
- **GIF** 到处都能用（聊天、论坛、邮件），但文件较大。拿不准就选 GIF。
- **WebP** 比 GIF 小得多，画质更好，还可以有透明背景。所有新版浏览器都能显示，部分旧软件不支持。
- **WebM** 文件最小、播放最流畅，但它是视频：没有透明背景，生成耗时比片段本身更长（实时录制——请让标签页保持在前台）。
- **质量**（WebP 和 WebM）：高、中、低。质量越低，文件越小。
- 如果 WebP 或 WebM 是灰色的，说明你的浏览器无法生成该格式。请使用最新版的 Chrome、Edge 或 Firefox。

## 用视频制作 GIF——一步一步来
1. 点击 **🎬 视频转 GIF** 标签页。
2. 点击左侧的文件按钮，从你的设备中选择一个视频（MP4 和 WebM 可在所有现代浏览器中使用；MKV 和 HEVC 取决于浏览器和设备）。视频不会上传到任何地方，数 GB 的大文件也可以。
3. 选择你想要的片段：在视频下方的进度条上拖动，使用 **在此设为开始** / **在此设为结束**（快捷键 `I` / `O`），或直接输入时间。**▶ 播放片段** 可预览。2–6 秒的短片段效果最好。
4. 设置 **输出宽度**（GIF 的宽度，480 是不错的起点）和 **FPS**（每秒图片数，15 看起来就很流畅）。数值越小，文件越小。
5. 选择文件类型并点击蓝色按钮。在进度条走满之前，请让标签页保持在前台。
6. 点击蓝色下载按钮。如果是 GIF，可以先点击 **在 GIF 编辑器中编辑** 来添加文字。

## 编辑已有的 GIF
1. 打开 **🎨 GIF 编辑器** 标签页，在左侧选择你的文件：GIF、图片、视频、**动态 WebP** 或 **WebM**。也可以直接拖放文件。
2. 点击 ▶ 播放。拖动滑块可以逐张查看画面（帧）。
3. 在 **编辑** 中：**起始帧** / **结束帧** 用来去掉开头或结尾，**速度 ×** 让它更快或更慢，**倒放** 反向播放，**FPS**（最大 50）和 **输出宽度** 改变流畅度和大小，**裁剪** 用来裁切画面。
4. 选择文件类型，点击蓝色按钮并下载结果。操作错了？点击顶部的 **撤销**。

## 裁剪 GIF
1. 在 **🎨 GIF 编辑器** 标签页中打开一个 GIF。
2. 点击预览上方的 **✂ 裁剪**。整个 GIF 会出现在预览区中央：要保留的部分高亮显示，其余部分变暗。
3. 拖动亮框的边缘或角来裁切；在框内拖动可以移动它。**裁剪** 和 **输出宽度** 旁边的数值会自动跟随变化。
4. 再次点击 **✂ 裁剪** 即可回到普通预览。裁剪时，框外的图层会被隐藏。

## 添加文字、图片和手绘
- **+ 文字** 可在 GIF 上添加文字。在左侧的输入框中输入内容，选择字体、大小和颜色，再把文字拖到合适的位置。**双击画面中的文字即可再次编辑**（也可以在图层列表中双击）。
- **+ 图片** 可添加你自己的图片，例如徽标。**✏️ 绘制** 可用鼠标或手指涂画。
- 每个文字、图片或手绘都是一个 **图层**。在列表中点击图层即可选中；▲ ▼ 可上移或下移，✕ 可删除。**从此帧起可见** / **到帧** 决定图层在何时显示。
- 在图层上滚动鼠标滚轮 = 缩放，Shift + 滚轮 = 旋转。图层也可以拖到画面之外（变暗的边缘），之后再拖回来。

## 让内容动起来
- **快捷方式：** 选中一段文字或一张图片，点击某个效果：淡入、飞入、脉冲、摇晃、旋转或弹跳。
- **自己动手：** 勾选 **启用动画（关键帧）**，跳到另一帧，把图层拖到新位置。中间的运动由 OrcaGif 自动补全。需要的话还可以选择缓动方式。

## 这些词是什么意思？
- **帧** – 动画中的一张单独画面。GIF 就是许多帧快速依次播放。
- **FPS** – 每秒显示的画面数。数值越大越流畅，但文件也越大。
- **输出宽度** – 成品文件的宽度，单位是像素（屏幕上的小点）。
- **抖动（Dithering）** – GIF 最多只能用 256 种颜色。这个技巧会混入细小的点，让天空和皮肤看起来更平滑。照片和视频建议开启，徽标和纯色图案则保持关闭。（仅适用于 GIF。）
- **透明背景** – 透明的部分会露出图片后面的内容。GIF 和 WebP 支持此功能。
- **图层** – 叠放在 GIF 之上的文字、图片或手绘。
- **关键帧** – 在某一时刻保存下来的位置、大小或角度。OrcaGif 会自动补全两个关键帧之间的运动。
- **水印** – 角落里的小字“OrcaGif”。默认开启——请保持开启，以支持这个免费工具。

## 文件太大怎么办？
减小 **输出宽度**、降低 **FPS**，或缩短片段——也可以选择 **WebP**。如果 GIF 的颜色看起来有色块，请开启 **抖动（Dithering）**。
